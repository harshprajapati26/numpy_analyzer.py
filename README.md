# 🔢 NumPy Analyzer

A menu-driven Python application that combines **NumPy functionalities** with **Object-Oriented Programming (OOP)** principles. It allows users to perform array operations, mathematical calculations, searching, sorting, filtering, and statistical analysis through an interactive console interface.

## 🎯 Objective

The objective of this project is to develop a NumPy Analyzer toolkit that enables users to perform common data operations, statistical calculations, and mathematical computations on NumPy arrays using an organized, object-oriented approach.

## ✨ Features

### 📦 Array Management
- Create 1D, 2D, and 3D NumPy arrays.
- Access array elements using indexing.
- Extract specific elements using slicing.
- Combine multiple arrays.
- Split arrays into smaller arrays.

### ➕ Mathematical Operations
- Addition
- Subtraction
- Multiplication
- Division
- Dot Product
- Matrix Multiplication

### 🔍 Search, Sort & Filter
- Search for specific values in arrays.
- Sort arrays in ascending and descending order.
- Filter array elements based on user-defined conditions.

### 📊 Aggregation Functions
- Calculate the sum of array elements.
- Calculate the mean (average).
- Calculate the median.
- Calculate standard deviation.
- Calculate variance.

### 📈 Statistical Functions
- Find minimum and maximum values.
- Calculate percentiles.
- Calculate correlation coefficients between arrays.

### 🏗️ Object-Oriented Programming (OOP)
- Implement a `DataAnalytics` class.
- Use constructors for array initialization.
- Encapsulate functionalities using methods.
- Use private methods for internal computations.
- Implement class methods (`@classmethod`).
- Implement static methods (`@staticmethod`).

### 🖥️ User Interface
- Interactive, menu-driven console interface.
- Multiple options for performing array operations.
- User-friendly navigation between operations.
- Exit option from the main menu.

## 🛠️ Technologies Used

- **Python**

- **Object-Oriented Programming (OOP)**

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/NumPy-Analyzer.git
```

### 2. Navigate to the Project Directory

```bash
cd NumPy-Analyzer
```

### 3. Install NumPy

```bash
pip install numpy
```

### 4. Run the Program

```bash
python main.py
```

> Replace `main.py` with your actual Python filename if it is different.

## 📖 How to Use

After running the program, the main menu will appear:

```text
Welcome to the NumPy Analyzer!

========================================
Choose an option:

1. Create a Numpy Array
2. Perform Mathematical Operations
3. Combine or Split Arrays
4. Search, Sort, or Filter Arrays
5. Compute Aggregates and Statistics
6. Exit
```

Select an option by entering its corresponding number.

### 1️⃣ Create a NumPy Array

Create arrays of different dimensions:

- 1D Array
- 2D Array
- 3D Array

Enter the required dimensions and array elements.

### 2️⃣ Perform Mathematical Operations

Perform mathematical operations between arrays:

- Addition
- Subtraction
- Multiplication
- Division

### 3️⃣ Combine or Split Arrays

- Combine multiple arrays.
- Split an existing array into smaller arrays.

### 4️⃣ Search, Sort, or Filter Arrays

- Search for a particular value.
- Sort array elements.
- Filter values according to conditions.

### 5️⃣ Compute Aggregates and Statistics

Calculate statistical values such as:

- Sum
- Mean
- Median
- Standard Deviation
- Variance
- Minimum
- Maximum
- Percentiles
- Correlation Coefficient

### 6️⃣ Exit

Exit the program safely using the Exit option in the main menu.
